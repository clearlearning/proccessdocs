Overview

The Litmos Historical Data tool allows you to look up completion records for attendees who participated in NCIT programs before April 2023. Before that date, all users were in the Litmos LMS. This data is not available in TalentLMS.

Use this tool when you receive a request for information about an attendee from a pre-April 2023 program.

Before You Begin

Make sure you have the following:

  • Access to the CLEAR Learning Administrative Tools Dashboard

  • The attendee’s name, email, or other identifying information

Process Guide

Step Action
1 From the Administrative Tools Dashboard, click the Litmos Historical Data card to open the tool.
2

Enter search criteria using any of the available fields:

  • First Name or Last Name

  • Email

  • Company/Organization

  • Course

  • Team (equivalent to cohort)

  • Program Start Month

Tip: If the attendee knows when they participated, use the team/cohort field. For example, a US Basic program from July 2021 would be 2021 07 NCIT B US Open.

Step Action
3 Click the Search button. The tool will display all users matching your search criteria.
4

Click on the user’s name to expand their details. The user header displays:

  • Name and email address

  • Organization

  • Number of courses assigned
5

The expanded section shows:

  • Title, location, and NCIT Basic ID (used for Prometric exam registration)

  • Team/cohort assignments from the previous system

  • Accordions for each assigned course
6

Click on any course accordion to expand it and review module completion status. For each module:

  • Green checkmark = Completed (with completion date)

  • Gray field = Not started or in progress
