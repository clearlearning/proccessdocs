Overview

The Exam Report Generator pulls final exam data from TalentLMS, provides question-level analysis, imports payment data from Novi, issues digital badges through Credly and sends exam reminder emails via Power Automate.

This guide covers the full process from pulling exam data through issuing digital badges in Credly, as well as the process for assigning the final exam to a cohort.

After all steps are complete you will have a complete report by cohort containing exam scoring, payment confirmation, badge issue dates and certificate assignment dates.

Before You Begin

Make sure you have the following:

  • Access to the CLEAR Learning Administrative Tools Dashboard

  • Your CLEAR Learning Portal auth token (saved automatically after first use)

  • Your Credly auth token (available in the credly admin portal)

  • Access to the CLEAR Staff SharePoint site (for exam reminder emails)

  • Access to the NoviAMS admin portal (Events tab)

  • Access to Credly (credly.com) with organization-level permissions

Note: If this is your first time using the tool, you will need the auth token provided by your administrator. After the first successful connection, the token is saved in your browser automatically.

Process Guide

Part 1: Pull and Review Exam Data

Step Action
1 From the Administrative Tools Dashboard, click the Exam Report Generator card. If you are not automatically connected, click the Test Connection button.
2

Select the final exam course for the program from the Course (Exam Program) list.

Note: For Online programs, make sure to select the final exam course, not the program course. In-Person programs contain the test within the course.
3

Select the cohort from the Group (Cohort) list and verify that the value in the Exam Type field matches the program. If it does not, delete the contents of the field to view the list of options.

Exam types: NCIT Basic US Final Exam (74 Qs), NCIT Basic Canadian Final Exam (72 Qs), NCIT Specialized (60 Qs)
4 Click the Pull Exam Data button. The tool will display a list showing how each cohort member performed.
5

Navigate to the Question Analysis tab. Review the data to identify any questions with a higher-than-expected failure rate.

Exclude any identified questions by clicking on the question number and then clicking the Recalculate Adjusted Grades button.

Tip: To reverse the exclusion, return to the Question Analysis tab, unselect the question, and recalculate again.

Part 2: Import Payment Data

There are two ways to pull payment data from Novi.

  1. Automatically though the connection in the tool

  2. By manually exporting the attendee data from Novi and uploading into the tool

The steps for both options are below.

Automated Process (Preferred)

Step Action
6 Navigate to the Payment Import tab
7 Enter the Auth token if necessary (it is the same one used for the main page) and click the Connect button
8 Select your event from the list. Events are in chronological order from furthest future date to furthest past date. Type to filter the NOVI EVENT field by start date, event name, or event type.
9 Once you have located the appropriate event, click the Pull Payment Data button.

Note: You will see a confirmation message once the data pull is complete. Once you see that, navigate back to the Exam Report tab to confirm the data pull was successful.

Manual Process (Backup Process)

Alt-Step Action
6 In the NoviAMS admin portal, navigate to the Events tab and open the event for the cohort.
7 From the Attendees tab, click the Excel icon above the attendee table and select All Fields. This will download an export of registered attendees.
8 Return to the Exam Report Generator. Drag and drop the downloaded file into the Payment Import area. A Yes or Unpaid marker will appear next to each registered attendee.

Note: Blank payment markers typically indicate CLEAR staff accounts or the CLEAR Learning example account. These can be ignored.

Part 3: Send Exam Reminder Emails (If Applicable)

Note: Exam reminders are sent at two points during the testing window: halfway through the window and the day before the window closes.

Step Action
10 In the Exam Report Generator, navigate to the Email Reminders tab. Here you will see all attendees assigned to the cohort, who have been assigned to the final exam, and have not completed it.
11

Enter the appropriate date in the Exam Deadline field, remove any attendees you do not wish to generate a reminder for, and click the Generate Reminder Emails button.

Note: Deselect any accounts that you do not wish to generate an email for. This is typically clear staff or demo accounts.

Note: This does not send the emails. It generates the email files for export.

Step Action
12 Verify the deadline in the pop-up confirmation and click Continue. Review the email preview.
13 Click the Export Emails for Power Automate button to download a zip folder. Unzip the folder and upload the files to the SharePoint ExamReminders folder following the same process as the Status Report Generator (see the Status Report Generator Process Guide, Part 2).

Part 4: Send Exam Failure Notifications

Note: When a learner fails an exam, CLEAR offers the option to retake the exam. The below process allows you to automatically generate the form email that will inform the learners that they failed and what to do next should they wish to retake the exam.

Step Action
14 Navigate to the Email Reminders tab
15 Click the X Exam Failed Notice button
16 De-select any users from the list as needed.
17 Populate the Retake Fee, Contact Email and Retake Access Duration fields as appropriate.
18 Click the Generate Exam Failed Emails button and review the preview field.
19 Click the Export Emails for Power Automate button to download a zip folder. Unzip the folder and upload the files to the SharePoint ExamReminders folder following the same process as the Status Report Generator (see the Status Report Generator Process Guide, Part 2).

Part 5: Issue Digital Badges

There are two ways to issue digital badges, through the Exam Report Generator, or via manual upload. Through the generator is the preferred method but the manual upload is available as a backup.

Automated Process (preferred)

Step Action
20 Navigate to the Credly Badges tab.
21

If not already connected, click the Connect button.

Note: If you do not have the Credly API token, it is available in the Credly Admin portal.

  1. Click on the login icon in the top right corner

  2. Select the Developers menu option

  3. Navigate to the Authorization Tokens tab

  4. Copy the active token (look at the created on and expires at dates)
22

Click the Check Issued Badges button.

Note: It may take 30 – 60 seconds for the system to pull the badge eligibility results.
23 Click the Issue Badges via Credly API button. The system will connect with Credly and upload the badges for delivery.

Manual Process (Back Up)

Alt-Step Action
20 Click Export XLSX to download the cohort exam report. Use this file to update the master tracking spreadsheet after the cohort ends.
21 When you are ready to issue digital badges, click Export Credly CSV. This creates a pre-formatted file for upload to Credly.
22 Go to credly.com and sign in. If needed, navigate to your organization page using the profile menu.
23 Click the Issue tab, then click Upload CSV. Select the Credly CSV file from your Downloads folder.
24 Under the Replace credentials identified as duplicates? Heading, select No. If someone has already earned a badge, it does not need to be reissued.
25 Select the checkbox to send notification emails, then click Issue. Credly will process the badges and display a confirmation of how many were issued.

Download the Exam Report

This is an option part of the process. And can be used to:

  • Provide a final accounting of attendee results for a program

  • Confirm what digital badges and certificates have been issued and when

  • Quickly see who has completed the exam and if they have paid their event fee

Once you have completed all of the steps above (excluding alternate steps unless needed) navigate back to the Exam Report tab. Now the Paid, Digital Badge Issued, and Certificate Assigned fields have all been populated with the most current information.
