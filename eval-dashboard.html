Overview

The Module Evaluation Report Generator is a browser-based tool used to process, analyze, and export CLEAR Learning module evaluation data. It reads evaluation data from two SurveyMonkey Surveys (ILT and Async), provides filtering and analysis capabilities, and generates instructor-specific PDF reports and Excel files for updating the Master Instructor Workbook.

Before You Begin

Ensure you have access to the following:

  • Instructor Master Workbook — Located in the CLEAR Staff SharePoint site under CLEAR Shared > CLEAR Learning Facilitation > 08 Evaluations > Module Evaluations

  • Access to the CLEAR Learning Administrative Tools dashboard

Process Guide

Step 1: Analyze Data (Optional)

The Analyze tab allows you to explore the evaluation data from multiple angles. Use the filters to narrow results by:

  • Source (async vs IPT)

  • Program, Version, Method

  • Cohort and Instructor

  • Module (multi-select)

  • Date range

Select your criteria and click Apply Filters to view the results. This tab is for data exploration only and does not generate exportable reports.

Step 2: Generate Instructor Reports

Click the Instructor Reports tab to begin the export workflow.

In most cases, select the target Cohort from the cohort dropdown. Apply additional filters as needed, then click Generate Report.

The report will display:

  • A (No Instructor) tab if the cohort contains asynchronous modules

  • Individual tabs for each instructor associated with the cohort

  • Evaluation scores by module for each instructor

  • Open-ended comments with checkboxes for inclusion/exclusion

Auto-Filtered Comments: Comments containing only NA, N/A, None, or No Comment are automatically deselected and appear grayed out with strikethrough. You can re-select them by clicking the checkbox if needed.

Step 3: Review and Filter Comments

Click through each instructor tab to review their scores and comments. To remove a comment from the final report:

  • Uncheck the checkbox to the left of the comment

  • The comment row will appear grayed out and struck through

  • Only checked comments will be included in the PDF and Excel downloads

Use the Search box to find specific comments, or the Select All / Deselect All buttons for bulk operations.

Step 4: Export Reports

Once you have reviewed all comments for all instructors, use the export buttons:

Download PDF — Generates a separate PDF file for each instructor. These are the reports you send to the instructors. You may need to allow multiple downloads in your browser if this is the first time.

Download XLSX — Generates individual Excel files for each instructor. These files are used to update the Master Instructor File in the next step.

Note: Each exported Excel file contains per-module data with the cohort name, course, version, method, scores, and overall averages derived directly from the evaluation data.

Step 6: Update the Master Instructor File

Click the Update Master Instructor File button to navigate to the updater tool. Follow these steps:

Section 1: Upload Evaluation Reports

From your downloads folder, upload the instructor Excel files that you just created.

Important: Do NOT upload the file for (No Instructor). This file contains asynchronous module data and should not be added to the Master Instructor Workbook.

You can upload multiple files at once by selecting them all in the file browser, or drag and drop them into Section 1.

Section 2: Upload Master Instructor Workbook

Navigate to the CLEAR Staff SharePoint site:

CLEAR Shared > CLEAR Learning Facilitation > 08 Evaluations > Module Evaluations

Locate the Master Instructor Workbook Excel file. Drag and drop it into Section 2 of the updater tool.

Review and Update

The tool will display a preview showing:

  • The number of report files, instructors, and rows to be added

  • Which instructor tabs already exist (Existing tab) and which will be created (New tab)

  • A data preview of all rows that will be appended

Review the preview and click Update & Download to generate the updated workbook. The file will download to your downloads folder.

Step 7: Replace the File on SharePoint

Navigate back to the Module Evaluations folder on SharePoint:

CLEAR Shared > CLEAR Learning Facilitation > 08 Evaluations > Module Evaluations

Copy and paste the newly downloaded Master Instructor Workbook file into this folder, replacing the original file.

Step 8: Verify the Update (Optional)

Open the updated workbook to verify the contents:

  • The Master tab contains a list of all known instructors with their current overall standings across all modules.

  • Click an instructor name in Column A to navigate to their individual tab.

  • Each instructor tab shows a line item for every module they have taught in every cohort.

  • Click Back to Master in Column N to return to the Master tab.
