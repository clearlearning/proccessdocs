Mark Attendees as Attended in Novi

Overview

This process will show you how to mark those who have registered for and attended a program as attended in Novi.

Process Guide

Step Action
1 Navigate to https://clearhq.org/admin/events/event-lists
2 Locate the event from the list and click on the event name
3 Click the checkbox in the header row to select all registered attendees
4 Review the list and de-select any who did not attend the program
5 Click the Batch actions drop down button
6 Select the Mark as Attended button
7 Sort the list by the Attended column until those not marked as attended show at the top
8 Click the No icon (circle with a line through it) for those that did not attend
