Purpose

The NCIT Standard Release Status Report Tool is a browser-based administrative tool that allows CLEAR Learning staff to quickly look up any NCIT cohort, check which learners have completed their program's Standard Release, and generate personalized reminder emails for those who have not. It connects directly to TalentLMS via the CLEAR Learning API proxy and exports email files ready for the Power Automate send process.

When to Use This Tool

Use this tool when:

  • An NCIT in-person or online program session is approaching and you need to verify that all enrolled learners have completed the Standard Release.

  • You need a quick at-a-glance checklist for check-in staff showing which attendees still need to complete the Standard Release on arrival.

  • You need to send individual reminder emails to learners who have not yet completed the Standard Release.

  • You need a CSV export of cohort Standard Release status for your records.

Supported Programs

The tool supports the following five NCIT programs. Each is linked to its specific Standard Release course and test unit in TalentLMS.

Program Course ID Standard Release Name
NCIT Basic In-Person Program 161 NCIT Basic In-Person Program - Standard Release

Step-by-Step Process

Part 1: Access the Tool

Step Action
1 Go to the CLEAR Learning Administrative Tools dashboard.
2 Locate the NCIT Standard Release Status Report card in the Program Management section and click it to open the tool.
3 Verify the API connection indicator at the top of the tool shows green / Connected. If it shows red or disconnected, enter your Auth Token and click Test Connection.

Note

The tool auto-connects using your saved credentials from previous sessions. If this is your first time using the tool, you will need to enter the Auth Token once — it is saved for future use.

Part 2: Select the Program and Cohort

Step Action
1

In the Program dropdown, select the appropriate program from the list. The five options are:

  • NCIT Basic In-Person Program

  • NCIT Specialized In-Person Program

  • NCIT AIT In-Person Program

  • NCIT Specialized Online Program

  • NCIT Basic Online Program
2 In the Cohort / Group field, type to filter for the appropriate group and select it from the dropdown list.
3 A confirmation banner will appear showing the Standard Release course and test unit that will be checked for the selected program.
4 Click the Load Cohort Data button.

Part 3: Review the Cohort Report

Once the data loads, the Cohort Report section will appear with the following information:

Element Description
Total Learners The total number of learners enrolled in the selected cohort.
SR Completed The number of learners who have completed the Standard Release test.
Not Completed The number of learners who have not yet completed the Standard Release test.
Completion Rate The percentage of active (included) learners who have completed the Standard Release.

Below the summary cards are three tabs:

  • All Learners — complete list of all cohort members.

  • Incomplete / Not Started — learners who have not completed the Standard Release test.

  • Completed — learners who have completed the Standard Release test.

Part 4: Exclude Demo Accounts or Dropped Learners

If the cohort contains demo accounts, test users, or learners who have dropped out but remain in the TalentLMS group, you can exclude them from the report and email generation without deleting them from the system.

Step Action
1 To exclude individual learners, uncheck the checkbox in the leftmost column next to their name in any tab.
2 To exclude an entire tab's worth of learners at once, uncheck the select-all checkbox in the table header.
3 Excluded learners appear with strikethrough formatting and are removed from the summary counts and from all exports. An Excluded count will appear in the summary cards.
4 To re-include a learner, simply check their checkbox again. Excluded learners remain visible in all tabs so they can always be restored.

Tip — Quick workflow for email generation

To generate emails only for incomplete learners: go to the Completed tab, uncheck the select-all checkbox to exclude everyone who has already finished. Then proceed to the export section. Only incomplete active learners will receive an email.

Part 5: Generate and Export Reminder Emails

Step Action
1 Scroll down to the Generate Standard Release Reminder Emails section.
2 Enter the Program Start Date in the format: Month Day, Year (e.g., May 4, 2026). The Deadline Preview field will automatically update to show the deadline language that will appear in each email: prior to checking in on [date].
3 Click Export Reminder Emails (ZIP). A ZIP file will download containing one individual HTML email file per non-completed, included learner.
4 Optionally, click Export CSV to download a spreadsheet listing all cohort members and their Standard Release status. This is useful as a check-in reference for in-person programs.

Note

Each email file is named StandardRelease_email@domain.com.html. The file name is what the Power Automate process uses to identify the recipient — do not rename the files.

Part 6: Upload Files to SharePoint for Power Automate

Once the ZIP file has been downloaded, follow these steps to trigger the automated email send process.

Step Action
1 Locate the downloaded ZIP file and extract all files from it.
2 Open a web browser and navigate to the CLEAR Shared SharePoint site. Use the web browser version of SharePoint — do not use File Explorer or the desktop sync folder, as this can cause upload issues.
3 Navigate to: CLEAR Shared → CLEAR Learning Facilitation → Status Report Emails → Standard Release.
4 Upload all HTML files from the extracted ZIP folder into this SharePoint folder.
5 Power Automate will detect the new files and automatically send each email to the corresponding learner from the CLEAR Learning mailbox.
6 To confirm delivery, check the Sent folder in the CLEAR Learning mailbox.

Important

Always upload files using the SharePoint web browser interface to ensure the Power Automate trigger fires correctly. Files dragged in via File Explorer or the synced desktop folder may not trigger the automation.
