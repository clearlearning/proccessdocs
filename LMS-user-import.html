Overview

The User Import Tool uploads new users into TalentLMS for a program cohort. It takes an attendee export from NoviAMS, creates user accounts, sets up a cohort group, assigns program courses, and adds users to the group.

This tool can also be used to import users from Novi to an existing cohort. This will happen when attendees sign up after the cohort has been created.

This guide walks you through the full process from exporting attendees in Novi through verifying the import in TalentLMS.

Note: Novi Event Attendee Data can be automatically imported using the functionality of the tool; however, if for any reason a manual upload is required those steps are included below.

Before You Begin

Make sure you have the following:

  • Access to the CLEAR Learning Administrative Tools Dashboard

  • Access to the NoviAMS admin portal (Events tab)

  • Your CLEAR Learning Portal auth token (saved automatically after first use)

  • The cohort name, start date, and end date for the program

Note: The cohort description should include the start date (welcome session) and the end date (final day of the exam testing window).

Process Guide

Part 1: Export Attendees from Novi

This part will not be used unless a manual upload is required. For the standard process, proceed to part 2.

Step Action
1 In the NoviAMS admin portal, navigate to the Events tab and locate the event for your cohort.
2 From the attendee table, click the Excel icon above the table and select the All Fields option. This will download an Excel file of all registered attendees.

Part 2: Import Users into TalentLMS

Step Action
3 From the Administrative Tools Dashboard, click the User Import Tool card to open the tool.
4 Make sure the API Connection and Attendee Data Source sections are connected.
5 Select the appropriate event from the NOVI EVENT field. You can use type to filter and enter the start date for the event, the event type, or components of the event name to more easily find the appropriate event.
6 Click the Pull Attendees button.
Alt
5 – 6		 Drag and drop the attendee export file from your Downloads folder into the Upload Attendee File area. The tool will display the number of attendees detected.

Note: For this stage of the process, make sure the + Create New Cohort button is selected in the 3. Group & Course Configuration section.

7

In the Group Name field, enter the cohort name for the group you are creating.

Example: 2026.04.09 NCIT B US Open
8

In the Group Description field, enter the program start date and end date.

Example: 04/09/2026 – 05/02/2026

Tip: The start date is the date of the welcome session. The end date is the final day of the exam testing window.

Step Action
9 Click in the Add Courses to Group field to activate the drop-down menu, select the appropriate standard release course for the program, then click in the field again and select the program course itself.

Important: Do NOT select the final exam course at this stage for online programming. You are only assigning the standard release and the program course.

Step Action
10 Review the Import Preview table. Optionally, click Export Import File to save a record of the import for your files.
11 Click the Upload Users button. The tool will display results indicating how many users were uploaded and whether the group was created.

Note: If users already exist in TalentLMS, the tool will note this but will still add them to the new cohort group.

Step Action
12 Click the Add Users to Cohort button to assign the uploaded users to the cohort group.

Note: Steps 11 and 12 must be completed in this order. By breaking this process into two actions it gives TalentLMS time to make sure all users are created in the portal before they are assigned to the cohort. If done out of order you will receive an error message.

Part 3: Verify the Import

Step Action
13

In TalentLMS, using the Administrator role navigate to Groups, locate the group you just created, and verify:

  • The correct number of users are in the group

  • The courses are synchronized with the group
14 Optionally, check the Events Engine > Pending Notifications in TalentLMS to confirm that welcome notifications are queued.

Note: Once complete, verify that the correct number of participants were imported.

The next step in this process is to assign users to the live events for the session. See the Live Event Assignment process document for details.

Add Attendees to an Existing Cohort

If an attendee is added to the program in Novi after the cohort has been created using the above process, use the steps below to add the new attendee/s to the existing cohort.

Step Action
1 Repeat steps 3 – 6 from Part 2 above.
2 Click the Add to Existing Cohort button in the 3. Group & Course Configuration section.
3 Type to filter in the Search Existing Group field to locate the existing cohort.
4 Click the Create Users & Add to Cohort button.
5 Confirm additions to the program by navigating to the Events Engine in TalentLMS under the Administrator role and opening the Pending tab. Any users that have been added to the cohort should receive the welcome email for the programs associated with the group.

Note: Only attendees that are not already assigned to the cohort will be updated by this action. No attendees that are already in the cohort will be affected.

Troubleshooting

PLEASE NOTE: If users are not showing up in the cohort, go to the users tab and look them up. The most likely cause is that they were already in TalentLMS in an INACTIVE status. To fix this problem:

Step Action
1 Navigate to the user’s record in TalentLMS
2 Select the Active checkbox.
3 Click the Update user button.
4

Navigate to the Groups tab and confirm that the user has been added to the group.

  • If not, add them.

  • If yes, click the remove (-) icon in the Synchronize Users with Courses column for the group and then click the add (+) icon. This will trigger the welcome email for the course to be sent.
