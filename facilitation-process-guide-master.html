Create Live Sessions in TalentLMS

Open this guide on its own page ↗

Overview

This guide covers the process for creating live instructor-led sessions in TalentLMS for CLEAR Learning programs. Live sessions are scheduled within TalentLMS course modules and are used for both virtual (webinar) and in-person (classroom) delivery formats.

For virtual sessions, TalentLMS creates the corresponding Zoom webinar automatically through the CLEAR Learning Zoom account. In-person sessions are created entirely within TalentLMS with no Zoom configuration required.

Before You Begin

Ensure you have the following access and information:

Required Access & Information

  • Administrator-level access to the CLEAR Zoom account

  • Instructor-level access to TalentLMS as the CLEAR Learning Administrator

  • The course name and module where the live session will be added

  • Session details: date, start time, and duration in minutes

Virtual vs. In-Person: The process for creating virtual and in-person sessions is nearly identical. The key differences are noted throughout this guide. In-person sessions do not require any Zoom configuration.

Quick Process Guide

Virtual (Webinar) Sessions
Step Action
1 Log into TalentLMS as an administrator. Navigate to Users, search for learning, and click the Login to Account icon for the CLEAR Learning user.
2 Switch to the Instructor role. Navigate to the target course and module.
3 Click Edit on the module, then click Add Session.
4 Enter the session name, date, start time (set AM/PM first), and leave Capacity blank.
5 Set Instructor to CLEAR Learning. Set Type to Webinar. Check Create a new webinar. Set the duration. Click Add Session.
6 In Zoom, navigate to Meetings, locate the new event, and click the meeting name.
7 Click Edit to update any details as needed.
In-Person (Classroom) Sessions
Step Action
1 In TalentLMS, switch to the Instructor role. Navigate to the target course and module.
2 Click Edit on the module, then click Add Session.
3 Enter the session name, date, start time (set AM/PM first), and leave Capacity blank.
4 Set Instructor to CLEAR Learning. Set Type to Classroom. Set the duration. Click Add Session.

Note: In-person (classroom) sessions do not create a Zoom webinar. Once you add the session in TalentLMS, you are done.

Detailed Process Guide

Part A: Virtual (Webinar) Sessions

Step 1: Log into TalentLMS as the CLEAR Learning Administrator

Log into TalentLMS using the administrator role. Navigate to the Users tab.

In the search field, type learning. This filters the user list to display the CLEAR Learning user account.

Hover over the CLEAR Learning row in the list. In the options column, look for the ➜] icon. The tooltip reads Login to Account. Click that icon.

Why this matters: You must perform the following steps as the CLEAR Learning Administrator. This is required so that the live session is connected to the CLEAR Learning Zoom account, not your personal Zoom account.

Step 2: Switch to Instructor Role in TalentLMS

Now that you are acting as the CLEAR Learning Administrator, hover over the CLEAR Learning Administrator link at the top of the TalentLMS screen and select Instructor from the list of available roles.

Navigate to the course for which you are creating live sessions. Locate the module that holds (or will hold) the live sessions for the program.

Step 3: Add the Live Session

Hover over the target module and click the Edit link. Then click the Add Session button.

Complete the session form with the following settings:

Field Value
Name Enter the session name (e.g., the module title followed by month and year: Investigative Process – April 2026)
Date Select the date from the pop-up calendar
Start Time In the pop-up time selector, select AM or PM FIRST, then select the time by clicking on the hour then the minute
Capacity Leave blank
Instructor Set to CLEAR Learning (select from dropdown if not already set)
Type Select Webinar from the dropdown
Create a new webinar Check this checkbox (appears after selecting Webinar)
Duration Move the slider to the correct duration in minutes
Description Leave blank

Important: When setting the start time, you must select AM or PM from the buttons at the bottom of the time picker before selecting the time. If you select the time first, you will not be able to set AM/PM correctly.

Click Add Session to create the session.

Step 4: Configure the Zoom Webinar

Navigate to the Zoom account for the CLEAR Learning account. Go to the Meetings menu option.

Locate the event you just created in the list and click on the meeting name. Click Edit to update any details as required by process.

Module evaluations are no longer attached to Zoom sessions. Every module, instructor-led or asynchronous, has its own evaluation unit in TalentLMS. See Updating Module Evaluation Links for the current process.

Part B: In-Person (Classroom) Sessions

The process for creating in-person sessions follows the same steps as virtual sessions within TalentLMS, with the following differences:

Setting Virtual (Webinar) In-Person (Classroom)
Type field Select Webinar Select Classroom
Create a new webinar Check the checkbox Does not appear
Zoom configuration Required (Step 4) Not applicable

Key Difference: For in-person sessions, once you click Add Session in TalentLMS, you are done. There is no Zoom webinar to configure. All remaining session logistics (venue, materials, etc.) are managed outside of TalentLMS.

Assign Learners to Live Sessions

Open this guide on its own page ↗

Overview

This guide covers the process for assigning learners from a cohort to the live instructor-led sessions within their program in TalentLMS. This process applies to both virtual (webinar) and in-person (classroom) sessions.

Live sessions must already be created in TalentLMS before users can be assigned. See the Create Live Sessions in TalentLMS user guide for session creation instructions.

Before You Begin

Ensure the following before starting:

Prerequisites

  • Instructor role access in the CLEAR Learning TalentLMS portal

  • The live sessions for the program have already been created in TalentLMS

  • The cohort of learners has been imported into the program

  • You know which cohort you are assigning to sessions

Process Guide

Step 1: Navigate to the Program

Log into the CLEAR Learning portal and make sure you are in the Instructor role. Scroll down to or search for the program for which you are assigning users to live sessions and navigate to its homepage.

Step 2: Open the Live Session Module - Users Menu

From the program homepage, hover over the live session module (the module that contains the live sessions for the program). When you hover, a menu will appear. Click the Users option.

Step 3: Filter by Cohort

Click on the Course Users tab to display the list of all users enrolled in the course.

Click the filter icon located at the bottom right of the table. Select the cohort that you will be assigning to the live sessions. The table will update to show only the users from that cohort.

Step 4: Select All Cohort Users

Hover over the User column header at the top of the table. An empty checkbox will appear to the left of the header text. Click the checkbox to select all users in the filtered list.

Spot Check: Before proceeding, review the selected list to confirm that you have all the learners you need and that only members of the target cohort are selected. The filter should ensure this, but a quick visual check helps prevent errors.

Step 5: Assign Users to the Session

Click the Mass Actions dropdown button. From the menu, locate the Add to Session section and select the specific session you want to assign the users to.

A confirmation pop-up will appear asking if you are sure you want to perform this action. Click Add to confirm.

A notification will display at the top of the screen confirming how many users were added successfully.

Step 6: Verify the Assignment

To confirm the users were assigned correctly, click the Session Users tab.

In the dropdown list at the top right of the table, select the session name you just assigned users to. The table will display all attendees assigned to that session. Verify the list is complete.

Step 7: Repeat for Additional Sessions

If the program has multiple live sessions (e.g., multiple modules with ILT components), repeat Steps 2 through 6 for each session.

Update Completion Status for Live Sessions

Open this guide on its own page ↗

Overview

Programs containing live, instructor-led sessions require the program facilitator to mark attendance for the live session/s in TalentLMS. For virtual programs, this process is completed after each live session. For in-person programs, wait to take attendance until the end of the cohort training window.

Virtual Programs

When users attend a live virtual instructor-led session their attendance is automatically imported into TalentLMS from Zoom. To give credit for attending a session, we must update the learner’s status for the session.

Step Action
1 Navigate to the course in TalentLMS in the Instructor role.
2 Locate the instructor-led module and hover over the name until the menu appears. Select the Users menu option.
3 Locate the appropriate session in the session drop down list above the attendee table to the right.
4 Click the Mass grade users button above the user information table.
5 Remove the Pending option from the For users with status text box and replace with the Attended Webinar option.
Make sure the Status field displays the Passed option.
6 Click the Save button.

Note: Do not mark attendees as “Not Passed” on an ILT module until the end of the cohort’s access window. If an attendee is marked as “Not Passed” they will receive a course failed notification after they attempt any other module.

Once a cohort’s access window is complete, update all users who failed to complete the required modules or their alternates as “not passed”. These are the users who will still show as “pending” for any ILT modules.

1 Locate the ILT module, hover over the name and click the users menu.
2 Make sure the correct session is selected in the session list.
3 Click the Mass grade users button above the user information table again.
4 Make sure the For users with status text box displays the Pending option.
5 Change the Status field to display the Not passed option.
6 Click the Save button.

In-Person Programs

Attendance for in-person programs are processed the same way as Virtual programs with one difference: Attendance is not automatically generated due to there being no sign-in method for in-person events in TalentLMS.

Instead, take attendance in Novi, marking attendees as “Attended” when they sign in the first day. Later, after administering the final exam, use this list to identify anyone who did not attend, mark them as “not passed” and then mark all remaining “pending” attendees as passed for each day of the program.

For courses without a final exam, attendance will be handled after the cohort has completed to generate any associated certificates of completion.

Step Action
1 Navigate to the course in TalentLMS in the Instructor role.
2 Locate the instructor-led module and hover over the name until the menu appears. Select the Users menu option.
3 Locate the appropriate session in the session drop down list above the attendee table to the right.
4 Click the Mass grade users button above the user information table again.
5 Review the For users with status text box and make sure the Pending option is selected.
6 Review the Status field and make sure the Passed option is selected.
7 Click the Save button.
8 Hover over the Options column for any user who did not attend the daily session and select the pencil icon.
9 Display the Status drop-down menu and select the Pending option.
10 Click the Save button.

Update and Release Live Session Recordings

Open this guide on its own page ↗

Overview

After each live virtual instructor-led session, CLEAR makes available a recording of the session for attendees who either were unable to attend the session, or those who would like to review the session.

For the following programs, new recordings must be made and shared for every cohort:

  • Advanced Concepts in Regulatory Governance (ACRG)

  • Executive Leadership Program for Regulators (ELPR)

  • Getting the Most From Your Board – Skills for Effective Chairing (BCT)

  • Skills for the Regulatory Administrator – Staffing a Board (SAB)

These programs encourage attendees to share challenges and experiences that they have faced, which they may not wish for those outside of their cohort to hear. To foster an environment that encourages this sharing without the fear of reprisal, recordings of the sessions are ONLY shared with the current cohort and are removed once the cohort is complete.

All other programs (mainly any NCIT program) share a pre-recorded already available session, as this privacy concern is not an issue for these audiences.

TalentLMS Event Engine – Welcome Email Templates

Open this guide on its own page ↗

Overview

The CLEAR Email Template Editor is a browser-based tool that allows staff to quickly update cohort-specific information in welcome emails before sending them through the Events Engine in TalentLMS. Rather than editing raw HTML code, users fill out a simple form and the tool generates ready-to-paste email code automatically.

This guide covers everything you need to use the tool confidently, including what each template is for, which fields to fill in, and how to get the code into TalentLMS.

No coding required

The tool handles all HTML formatting. You only need to fill in the cohort-specific details such as dates, locations, and contact information.

How to Use the Tool

The tool works in three steps: select a template, fill in the cohort details, and copy the generated code into TalentLMS.

1

Select a Template

Click the button for the program you are sending a welcome email for. The button will highlight in burgundy to confirm your selection, and the form fields for that template will appear below.
2

Fill In the Fields

Complete the form fields with the cohort-specific information. Each field is labeled clearly and includes example text to guide you. Fields that are left blank will retain their placeholder text in the output.
3

Generate & Copy

Click the Generate Email Code button. The output will appear at the bottom of the page. Click Copy All to copy the complete email code, then paste it into TalentLMS.

Pasting Into TalentLMS

Once you have copied the email code, follow these steps to apply it in TalentLMS:

  1. Log in to TalentLMS using the Administrator role and navigate to the Events Engine tab.

  2. Locate the appropriate welcome email template for the course you are updating.

  3. Click into the body field of the email template.

  4. Select all existing content in the body field (Ctrl+A or Cmd+A).

  5. Paste the copied content (Ctrl+V or Cmd+V).

  6. Click the Update Notification button to save your changes.

Important

The copied content contains two lines. Line 1 is the email subject line and line 2 is the full HTML body. TalentLMS will interpret these correctly when pasted into the body field of the Events Engine template editor.

Downloading the Code as a File

Once you have generated the code click the Download as .txt button. The file will be saved to your Downloads folder and named after the program (for example, Executive-Leadership-Program-for-Regulators-In-Person-Training.txt).

Place this file in the appropriate cohort folder. This is useful in case the template gets changed and you need to change it back, this way you don’t have to regenerate the email, you can just copy and paste the same code.

Updating Module Evaluation Links

Open this guide on its own page ↗

Overview

Each module in TalentLMS, asynchronous or instructor-led, contains an embedded module evaluation unit that links learners to a SurveyMonkey survey. The survey link includes custom variables that automatically tag each response with the correct course, version, delivery method, and cohort — so you never have to sort or filter responses manually after the fact.

Because the cohort variable changes with every new cohort, the link inside each module must be updated before learners access the module.

Note: This process document addresses the three types of Survey links to generate:

  • Virtual Asynchronous Modules (Self-Study)

  • Virtual Instructor-Led Sessions (Zoom sessions)

  • In-Person Instructor-Led Modules

Each type has a slightly different process as outlined below.

Part 1: Virtual Asynchronous Module Evaluation Process Guide

Step 1: Generate the Survey Link

The Survey Link Generator tool (Available in the Administrative Tools Dashboard under the Evaluation Reporting heading) creates a pre-populated SurveyMonkey URL that automatically passes cohort and module information through to each survey response. Open the tool and complete the following fields:

Field Value
Survey Type Asynchronous Modules
Course The course abbreviation (NCITS, NCITB, etc.)
Version This is used to indicate US or Canadian versions of the basic course and to distinguish between NCIT Workshops (DDI, IRSM, Communications, and Ethics)
Method Async
Module Name The module identifier (M01, M02, etc)
Instructor Leave blank
Cohort Use TalentLMS Cohort Code (2026 05 NCIT B CAN Open)

Note: Once all fields are complete, click the Copy link button. The tool will display the full survey URL with all populated variables embedded.

Step 2: Update the Module in TalentLMS

With the generated link copied to your clipboard, follow these steps to update the module evaluation content in TalentLMS:

Step Action
1 Navigate to the course in TalentLMS
2

Locate the evaluation module.

Note: If there are multiple evaluation modules in the list, select the one that is not red.
3

Hover over the unit and click the edit menu option
4

Click the Code View button in the top right corner of the editor toolbar. It is the last icon on the right.
5

Scroll to the bottom of the code editor window and locate line 27. This line begins with an <a href= tag and contains the current survey link.

Highlight the entire URL — starting from https and ending at the closing quotation mark before the word target. Do not include the quotation marks themselves in your selection
6 Paste the new link you generated in Part 1. It will replace the highlighted URL.
7

Click the Save and View dropdown button and select Back to Units List to save and exit.

Step 1: Generate the Survey Link

Generate the survey link as done in Part 1 of this process guide; however, use the values provided below.

Field Value

Version This is used to indicate US or Canadian versions of the basic course and to distinguish between NCIT Workshops (DDI, IRSM, Communications, and Ethics)
Method V-ILT
Module Name The module identifier (M01, M02, etc)
Instructor

Select the instructor’s name from the drop-down list provided.

Note: If an instructor’s name is not listed, contact avance@clearhq.org
Cohort Use TalentLMS Cohort Code (2026 05 NCIT B CAN Open)

Note: Once all fields are complete, click the Copy link button. The tool will display the full survey URL with all populated variables embedded.

Step 2: Add the Survey Link to the Module in TalentLMS

Instructor-led modules follow the same process as asynchronous modules. With the generated link copied to your clipboard, complete Part 1, Step 2 to update the module’s evaluation unit in TalentLMS.

Modules with both instructor-led and asynchronous components: only the asynchronous evaluation link goes in the TalentLMS evaluation unit. Paste the instructor-led evaluation link in the Zoom chat near the end of the live session and ask participants to complete it.

Generate the survey link as done in Part 1 of this process guide; however, use the values provided below and generate a QR code instead of copying the link.

Zoom — Session Setup & Live Facilitation

Open this guide on its own page ↗

Overview

This guide covers the process for setting up and managing sessions in the Zoom dashboard before a session, and for using Zoom host tools while facilitating a live virtual session. Log into Zoom at zoom.com using the CLEAR Learning account, available in OnePassword.

Note: Sessions created through TalentLMS (instructor-led modules) are automatically created in Zoom. The process for creating those sessions is covered in the Create Live Sessions in TalentLMS process guide. This guide covers Welcome Sessions (created manually) and everything you do inside a live session as the host.

Part 1: Zoom Dashboard Setup

Complete all setup in the Zoom dashboard before the session begins.

Quick Process Guide

Creating a Welcome Session
Step Action
1 Log into Zoom using the CLEAR Learning account (credentials in OnePassword). Go to the Meetings menu.
2 Click Schedule a Meeting in the top right corner.
3 Enter the meeting name (e.g., NCIT Basic Welcome Session — April 2026).
4 Set the start date, time, and duration using the When fields. Welcome sessions are typically 1 hour.
5 Confirm the time zone is set to Eastern Time.
6 Check the Registration — Required checkbox. This generates the registration link used in the Novi event listing and TalentLMS welcome email.
7 Leave all other settings at their defaults. Click Save.

Module evaluations are no longer attached to Zoom sessions. Every module, instructor-led or asynchronous, has its own evaluation unit in TalentLMS. See Updating Module Evaluation Links for the current process.

Adding Polls to a Session

Most polls have already been created in Zoom. You select which ones apply to each session.

INTERNAL USE ONLY — CLEAR Staff

Purpose

This tool lets CLEAR staff register a whole group of people for a NOVI event at once, by uploading a spreadsheet of names and email addresses instead of entering each person individually in NOVI. Use it any time you need to register more than a handful of people for the same event — conference attendees, a workshop group, a committee, and so on.

The tool will, for each person in your list:

  • Check whether they already have a member record in NOVI, and link the registration to it if so.

  • Optionally create a new record in NOVI for people who don’t already have one — either as a Non-Member, or as a full Member (standalone or inheriting membership from a parent company).

  • Register them for the event under the correct ticket type, at that ticket’s real price.

  • Show you a clear pass/fail result for every person, so nothing silently fails.

Step 5: Import

Once every row has a ticket type assigned (and you’ve reviewed the Member Match column), click “Import Selected Registrants.”

  • A progress bar and status column show real-time pass/fail for each person as the import runs.

  • If a Member Only ticket is assigned to someone who isn’t an eligible member, the import is blocked before anything is sent, with the affected names listed — fix their ticket or membership status and try again.

  • Each registration is charged at the ticket’s real price (fetched in Step 2) and marked Unpaid, so it shows in NOVI as an open balance rather than a completed payment.

  • If anyone fails, use Retry Failed Rows to try them again without re-running the whole batch.

  • Export Failed Rows to CSV downloads just the failures, with the error message included, so you can review or hand them off.

Understanding the Purchaser Field

In NOVI, every registration has a Purchaser — the record considered to have registered/paid for the attendee — separate from the Attendee themselves.

Leave the Purchaser field blank and the tool will automatically use the attendee’s own matched (or newly created) member record as the purchaser.

Only fill it in when someone else, such as the parent member, should be the purchaser of record instead of the attendee. You can enter either:

  • An email address — the tool looks it up in NOVI the same way it matches attendees.

  • A NOVI UniqueID (GUID) directly, if you already have it — this skips the lookup and applies instantly. (preferred)

If you have many people all purchased by the same person, use the “Bulk-assign purchaser to selected rows” field in Step 4 rather than typing it into every row — select the rows, enter the purchaser’s email or GUID once, and click Apply to Selected.

Understanding Membership Status & Ticket Restrictions

This section covers the difference between the two ways a new record can join NOVI, and how the tool decides who’s allowed to use a Member Only ticket.

Standalone Member vs. Inheriting Member

Situation What To Do
Standalone Member This person has their own individual membership. Select a Member Type from the dropdown and leave the Parent Company GUID blank.
Inheriting Member This person’s membership comes from a parent. Leave Member Type blank and enter the Parent Company’s GUID instead. NOVI computes their membership status from that link automatically.

Who Qualifies for a Member Only Ticket

When a ticket is flagged Member Only in Step 2, the tool checks each assigned row before allowing import:

  • A matched existing record qualifies only if NOVI reports their status as an active member or an inheriting member — simply having a NOVI record is not enough, since NOVI tracks Non-Members and Prospects in the same members table.

  • A newly created record qualifies only if you set its Membership Status to Member (with a type or parent company) during Step 4b — a newly created Non-Member does not qualify.

  • A row with no record at all (a plain guest) never qualifies.

TIP

If someone with a legitimate membership is unexpectedly blocked from a Member Only ticket, their NOVI status may use a value the tool doesn’t yet recognize as eligible. Note their name and status and flag it — don’t work around the block by unchecking Member Only on the ticket, since that would remove the protection for everyone else on the list too.

Important Reminders

  • This tool is for internal CLEAR staff use only.

  • Registrations and any records created — Non-Member or Member — are written directly and immediately to NOVI. There is no draft or undo step.

Recording Your Decision in the Tool

Step Action Notes
1 Select a status Choose Approved, Denied, or Pending from the Status dropdown.
2 Set a review date (if applicable) For Pending decisions, a review date is recommended. The tool auto-calculates the date the participant will meet the one-year requirement. Adjust as needed.
3 Select your name Choose your name from the Reviewed By dropdown. This field is required.
4 Enter notes Add relevant context — reason for denial, payment status, exam status, or follow-up needed.
5 Click Save Decision The decision is saved immediately. The table updates to reflect the new status.

Each save adds a new entry to the Decision History log. Previous decisions are never overwritten, providing a full audit trail.

Exporting Results

After running a search, an Export to Excel button appears in the results bar. Clicking it downloads a CSV file containing all currently displayed records including certification status, review date, reviewed by, and notes. Apply any filters before exporting to get the results you need.

Troubleshooting

Issue Resolution
Submissions not loading Check your internet connection and confirm the auth token is set correctly. Try refreshing the page.
Novi Connect button stays stuck on “Connecting…” Refresh the page and try again. The Connect to Novi button is in the Search & Filter panel at the top of the page. If it continues to fail, verify your token is correct by testing it in the Exam Report Generator.
Novi events not loading after connect Confirm your token is valid. The tool loads up to 200 events — use the date or name search to filter if needed.
Participant not found in Novi registrations Try searching by last name only. The participant may be registered under a slightly different name or as an attendee under another person’s registration. Check the Novi event directly if needed.
User not found in TalentLMS Try searching by last name only. Remove suffixes (Jr., Sr., III). Use the User Lookup Tool to search TalentLMS directly.
No NCIT Basic courses showing for user The participant may not be enrolled in an NCIT Basic course. Verify enrollment in TalentLMS directly.
Save decision returns an error Confirm the SUPERVISOR_CERT_STATUS KV namespace is bound in Cloudflare. Contact Amanda Vance if the error persists.
Experience shows red but supervisor claims prior service Open the detail panel and check the Prior Regulatory Experience section. If prior experience was not entered on the form, ask the supervisor to resubmit with those dates included.
Participant shows in wrong cohort The participant may have been added to a different group in TalentLMS. Search for them by name in the User Lookup Tool.
