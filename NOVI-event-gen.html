Overview

This guide covers how to use the CLEAR Learning Novi Event Creator tool to create a new event listing in Novi. The tool pre-populates template content for all CLEAR Learning programs, streamlining the event creation process and standardizing content across cohorts.

This process applies to both virtual and in-person CLEAR Learning programs. Where steps differ between delivery formats, differences are clearly noted.

Before You Begin

Have the following ready before starting. Do not begin this process without them.

  • The program agenda, generated using the Program Agenda Generator tool and uploaded to Novi Files.

  • The Zoom Welcome Session registration link. Create the Welcome Session in Zoom using the CLEAR Learning login and copy the registration link before proceeding. This is the registration link, not the join link.

  • Confirmed program pricing.

Virtual programs only: You must create the Welcome Session Zoom meeting and have the registration link ready before starting. The registration link is entered directly into the tool and populates all program communications.

Part 1: Select Your Program and Enter Cohort Details

1

Navigate to the Novi Event Creator tool

Navigate to the CLEAR Learning Automations Tool Dashboard and select the Novi Event Creator app. You will see a grid of all available CLEAR Learning programs.
2

Select the correct program tile

Click the tile for the program and delivery format you wish to create. Note the following:

  • NCIT Basic has four tiles: Canadian Virtual, US Virtual, Canadian In-Person, and US In-Person. Select the correct one.

  • Programs that do not specify virtual or in-person are offered in only one format. For example, AIT is in-person only; some workshops are virtual only.

  • If a program is not currently available in a particular format, the tool cannot be used to create it.
3

Select the month and year

In the Cohort Details section, select the month from the drop-down and enter the year. This will automatically:

  • Generate the event title in the standard naming format (program name + month + year).

  • Populate the Internal Notes Name field with the cohort name in TalentLMS format (e.g., 2027.01.01 NCIT B CAN Open).
4

Verify the auto-populated fields

Confirm the following fields populated correctly:

  • Event Title — should reflect the program name, month, and year.

  • Overview / Short Description — auto-populated from the program template.

  • Internal Notes Name — the cohort name used in both TalentLMS and Novi. Important for cross-system consistency.

The Internal Notes Name field defaults the day (DD) to 01 until you enter the program start date. Once you enter the start date in the Date & Time section, the DD updates automatically to match.

Part 2: Date, Time, and Location

5

Enter the start date and time

In the Date & Time section, enter the start date and time as follows:

  • Virtual programs: Enter the date and start time of the Welcome Session (typically 11:00 AM Eastern).

  • In-person programs: Enter the date and start time of Day One (typically between 8:00 and 9:00 AM local time).
6

Enter the end date and time

Enter the end date and time as follows:

  • Virtual programs: Enter the date and end time of the final Program Review and Test Prep session (typically ending at 1:00 or 2:30 PM Eastern).

  • In-person programs: Enter the last day of the program and the expected end time (typically between 3:30 and 5:00 PM local time).

Virtual programs are always in Eastern Time — do not change the time zone. For in-person programs, select the time zone of the training location.

7

Complete the location section

Virtual programs:

  • Virtual Location Name: This should always be Welcome Session Zoom Registration Link.

  • Meeting URL: Paste the Zoom registration link you created before starting this process.

In-person programs:

  • Enter the venue name, address lines, city, state/province, zip code, and country.

  • If a hotel block has been negotiated, enter the Hotel Booking Link URL and the rate deadline date.

  • Enter the Cancellation No-Refund Date.

  • Check-In Time / Training Start: Enter the registration window in the following format: 7:30 to 8:00 AM on May 4, 2026. Follow the hint text in the field for correct formatting.
8

Enter the Program Agenda link

In the Program Agenda Link field, paste the URL to the agenda file in Novi Files. You should have uploaded this before starting. This link auto-populates in the primary details, post-registration message, and ticket confirmation email.

Part 3: Review and Edit Event Descriptions

The Event Descriptions section contains three text fields pre-populated from the program template. As you enter location information and the agenda link, placeholder values in these fields update automatically.

9

Review the Primary Details field

This is the main event description visible on the event landing page. It includes the program overview, delivery format, session structure, technical requirements, and cancellation policy. All program content is in this field — CLEAR Learning no longer divides content between Primary and Secondary Details.

Make any necessary edits using the Rich Text editor (default) or switch to HTML view for precise formatting. Use the Copy HTML button to copy field content to your clipboard.
10

Review the Post-Registration Message

This is what registrants see immediately after completing their purchase in the Novi portal. It confirms their registration, provides next steps, and includes the Welcome Session registration link for virtual programs. Review and edit as needed.
11

Review the Ticket Confirmation Email

This email is sent to registrants after purchase. It contains more detailed next-steps information than the post-registration message. This content applies to both tickets. Review and edit as needed.


Part 4: Review Ticket Pricing

The Tickets section pre-populates with the standard member and non-member pricing for the selected program. Verify the pricing is correct before creating the event. Do not change ticket names or ticket details unless specifically instructed.

12

Verify ticket pricing

Confirm that Ticket 1 (CLEAR Member Registration) and Ticket 2 (General Event Registration) show the correct prices for this program. Update the price field if needed.

Part 5: Create the Event

13

Click the Create Event in Novi button

Once all information is entered and verified, click the Create Event in Novi button at the bottom of the form. The tool will display progress as it creates the event and both tickets in Novi.
14

Access the event in Novi

When the event is created successfully, two buttons will appear:

  • Open Novi Admin — Opens the Novi Events list. Search for the event by typing the month and year (e.g., January 2027) to locate it quickly.

  • View Event Page — Opens the public-facing event page to preview how it will appear to registrants.

Part 6: Complete the Post-Creation Checklist

After the event is created, a detailed checklist appears below the result. This checklist is program-specific and walks you through every manual step required to finalize the event in Novi. Use the checkboxes to track your progress.

Details Tab

15

Upload the event logo

In Novi, open the event and go to the Details tab. Website logos are stored in the CLEAR Learning SharePoint Logos folder — the link is provided in the checklist. Click the upload button under the Logo section, navigate to the appropriate logo file, and open it to upload.
16

Upload the agenda PDF

Scroll to the Agenda section of the Details tab. Click the Upload File button under the Upload PDF Agenda label. Upload the agenda file from Novi Files or the cohort folder in SharePoint. Do not use the Add Agenda Item button — that creates an agenda within Novi rather than attaching a downloadable file.
17

Set the event contact

In the Event Contact section, select Association Staff from the contact type list. In the Name field that appears, select the appropriate staff member from the drop-down.
18

Update the Post-Registration Message

The Post-Registration Message must be pasted into Novi manually:

  • Click the Copy Post-Registration HTML button in the checklist. This copies the formatted HTML to your clipboard.

  • In Novi, open the event and go to the Details tab. Locate the Post-Registration Additional Details field.

  • Click the Code View icon (< >) in the text editor toolbar to enable HTML editing mode.

  • Paste the copied HTML into the editor and click Save Code.

Tickets Tab

Complete the following steps for each ticket. The checklist in the tool has a separate section for each ticket with the exact values to enter.

19

Open Ticket 1: CLEAR Member Registration

In Novi, click the Tickets tab and open the CLEAR Member Registration ticket.
20

Set visibility

Change the Visibility setting to Open (Anyone).
21

Set purchase restriction

In the Ability to Purchase / Attend section:

  • Restrict To: Select Logged-In Users with Member Benefits.

  • Restriction Level: Select Restrict Purchaser and Attendee.
22

Set accounting

In the Accounting section, select the Item and Class values listed in the checklist for this program. These values are program-specific and are provided in the checklist.
23

Set attendee form fields

Add the following fields to the attendee form in order. Click in the field name search box, type the field name, click Add, and toggle required/optional as noted.
Field What to Enter
Name Required
Job Title Required — after adding, drag this field up below Name using the drag handle
Company Required
Email Required
Phone Optional
ADA Optional
Terms & Conditions (T&C) Required
Internal Notes (Internal Use Only) Optional

NCIT Specialized only: Also add NCIT Basic (Internal Use Only) as optional, between Terms & Conditions and Internal Notes.

24

Save the member ticket

Click Save and Close.
25

Open Ticket 2: General Event Registration

Open the General Event Registration ticket and repeat steps 20–24 with one difference in the purchase restriction:

  • Restrict To: Select Specific Group/Committee.

  • In the field that appears, select Has User Account (Group).

  • Restriction Level: Restrict Purchaser and Attendee.

  • All other fields are the same as the member ticket.
26

Save the general ticket

Click Save and Close.

Settings Tab

27

Enable the pre-event reminder email

Click the Settings tab and check Send Attendees an Automated Pre-Event Reminder. A date and time field will appear.

Set the time before the date. The field defaults to 24 hours before the welcome session and requires a minimum of one hour before the start of the session, which blocks same-day date selection for virtual programs. Always set the time first, then the date.

  • Virtual programs: Set the time to 1 hour before the Welcome Session (e.g., 10:00 AM for an 11:00 AM session), then set the date to the Welcome Session date.

  • In-person programs: Set to 24 hours before Day One.
28

Set event capacity

Scroll to the Event Capacity field and enter the number provided in the checklist for this program. If a specific capacity has been agreed upon for this cohort (e.g., for a closed or hosted program), use that number instead.
29

Set Registration Open Until

In the Registration Availability section, set the Registration Open Until date and time:

  • Virtual programs: Set to the date and time of the Welcome Session.

  • In-person programs: Set to the date and time of Day One.
30

Save the settings

Click Save.

Activate the Event

31

Verify the Internal Notes field

Before activating, scroll to the Notes field in the event and confirm the cohort name is present. This should have been populated by the tool. If it is missing, enter it manually.
32

Activate the event

Once all checklist items are complete, navigate to the top of the event page in Novi and toggle the event status from Inactive to Active. The event is now live and visible to registrants.
