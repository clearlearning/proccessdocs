Overview

The User Lookup Tool allows you to search for individual users in the CLEAR Learning Portal (TalentLMS), review their course progress and exam scores, verify payment directly in Novi AMS, and mark programs as complete to issue certificates.

This guide covers the full certification verification and issuance process, from looking up a user through confirming payment and issuing their certificate in TalentLMS.

Before You Begin

Make sure you have the following:

  • Auth Token: Your CLEAR Learning worker auth token. Enter it once — it is saved in your browser for future sessions.

  • Novi Auth Token: Your Novi AMS auth token. Also saved after first use. The tool will attempt to connect to Novi automatically when the page loads if the token is already saved.

  • TalentLMS access: Administrator access to the CLEAR Learning Portal.

  • Certification application: The applicant’s Wufoo form submission or supervisor certification form, and supervisor letter confirming at least one year of regulatory investigative experience.

Note: Before issuing any certificate, confirm that the applicant has submitted their certification application, the supervisor letter confirms at least one year of regulatory investigative experience, the applicant has completed all required program components, and payment has been received.

Part 1: Connect to APIs

When the tool opens, the API Connection panel is at the top of the page. Both TalentLMS and Novi connect here.

Step Action Notes
1 Enter your Auth Token The Worker URL is pre-configured. Enter your CLEAR Learning auth token and click Test Connection. A green “Connected” message confirms the TalentLMS connection.
2 Enter your Novi Auth Token Enter your Novi token in the Novi Auth Token field and click Connect to Novi. A green confirmation message appears when connected. If your token was previously saved, both connections happen automatically on page load.

Part 2: Look Up the User

Step Action Notes
3 Search for the user In the Search Users field, enter the user’s name or email address. Select the correct match from the results list.
4 Review the user header The tool displays the user’s name, email, login, and all cohort group memberships.

Tip: If the user does not appear in search results, try searching by last name only. Remove any suffixes such as Jr. or Sr. If you still cannot find them, they may be enrolled under a different name in TalentLMS.

Part 3: Verify Program Completion

After selecting a user, their enrolled courses load as collapsible accordion cards. Each card shows course completion status and percentage.

Step Action Notes
5 Expand the program course Click the course header (e.g., NCIT Basic Online Program) to expand the module list.
6 Review module statuses The module table shows each unit’s name, type, completion status, and score. Only Test and Assignment type modules display a score — all other module types show “—” in the Score column. Modules are listed in the configured display order.
7 Verify the final exam Expand the Final Exam course (e.g., NCIT Basic Final Exam – US or Canadian). Confirm the exam was attempted and the score is 70% or higher.

Part 4: Verify Payment

After the course cards load, a Payment Verification panel appears below them. If Novi was already connected at the top of the page, the event search field is ready immediately.

Step Action Notes
8 Select the Novi event In the Novi Event field, type the program date (MM/DD/YYYY), name, or category to filter the dropdown. Click the correct event to select it.
9 Pull registrations Click Pull Registrations. The tool fetches all registrant records for the selected event and displays a count when complete.
10 Search for the participant The Participant Name field is pre-filled with the name of the user you looked up. Edit the name if needed (e.g., remove a suffix), then click Search.
11 Review payment status

A result appears showing the matched registrant name, email, and a payment badge:

  • ✓ Paid (green) — proceed to Part 5

  • ✗ Unpaid (red) — do not issue the certificate until payment is resolved

  • ? Unknown — verify in Novi directly

Tip: If the participant is not found, try searching by last name only. They may be registered under a slightly different name or as an attendee under another person’s registration. If multiple matches appear, click the correct registrant to confirm their payment status.

Important: If payment status does not show Paid, contact the applicant and let them know that payment must be received before the certificate can be issued.

Part 5: Issue the Certificate

Once all requirements are confirmed — program completion, exam score, and payment — use the Mark Course as Complete section at the bottom of the panel to issue the certificate.

Step Action Notes
12 Select the course In the Mark Course as Complete dropdown, select the appropriate program course (e.g., NCIT Basic Online Program or Canadian NCIT Basic Online Program).
13 Click Open in Portal TalentLMS opens in a new tab on the users-in-progress page for the selected course.
14 Complete the course In TalentLMS, search for the user by last name. Hover over their row and click the checkmark icon (tooltip: Complete) in the Options column.
15 Set the completion date In the Complete pop-up, select today’s date in the Completed On field and click Complete.

Note: If your TalentLMS session is not active, you will be prompted to log in first.

Tip: Completing the course automatically issues the certificate and sends the learner an email from the CLEAR Learning Portal. If a learner asks where to find their certificate, they can go to My Certificates under their profile. They do not need current course access to view earned certificates — only an active login.

Troubleshooting

Issue Resolution
User not found in search Try last name only. Remove suffixes (Jr., Sr., III). Check if the participant used a different name in TalentLMS.
No courses loading for user The user may not be enrolled in any courses. Verify enrollment in TalentLMS directly.
Novi Connect button stays on “Connecting…” Refresh the page and try again. Verify the Novi token is correct by testing it in the Exam Report Generator.
Participant not found in Novi registrations Try last name only. The participant may be registered under a different name or as an attendee under another person’s registration.
Payment shows Unpaid Contact the applicant. Do not issue the certificate until payment is confirmed.
TalentLMS login required when opening portal Your session has expired. Log in to TalentLMS first, then return to the tool and click Open in Portal again.
Certificate not issued after completing course Verify the correct program course was selected (not the exam course). The certificate is attached to the program course completion.
