Overview

The NCIT Supervisor Certification Review Tool is used by CLEAR Learning staff to review and process supervisor verification forms submitted by participants seeking NCIT Basic certification. This guide covers the full process from initial form review through verifying payment, confirming course completion, and issuing the certificate in TalentLMS.

Certification requires all four of the following to be confirmed before approval:

  • Attended a CLEAR NCIT Basic program and completed all required components

  • Passed the NCIT Basic Final Exam (score ≥70%)

  • Paid all required program fees in full

  • Demonstrated a minimum of one cumulative year of experience in regulatory investigations

Note: The Supervisor Certification Review Tool now verifies all four requirements. Payment verification (requirement #3) and course completion with exam scores (requirements #1 and #2) are confirmed directly within the tool’s Payment & Course Verification section. The NCIT Exam Report Generator is no longer required before processing a decision.

Before You Begin

Before opening the review tool, ensure you have the following available:

  • Auth Token: Your CLEAR Learning worker auth token, stored in your browser after first use.

  • Novi Token: Your Novi AMS auth token. Enter it once in the Search & Filter panel at the top of the page — it is saved in your browser and the tool connects to Novi automatically on every subsequent page load.

  • Internet connection: The tool makes live calls to TalentLMS and Novi AMS.

All payment and course verification is handled within the tool. You no longer need to run the NCIT Exam Report Generator before processing a decision.

Using the Review Tool

Searching for Submissions

The Search & Filter panel also contains the Novi Auth Token field and Connect to Novi button. Enter your token once and it is saved — on subsequent visits the tool connects to Novi automatically when the page loads. A green confirmation message appears in the panel when the connection is active.

The panel provides three search options and four filter options that can be combined:

  • Search By Program: Enter the program name, city, or partial date. Use this when processing a full cohort.

  • Search By Participant Name: Enter the participant’s first or last name for individual lookups.

  • Search By Current Agency: Enter the agency name to pull all submissions from a particular organization.

Use the filter row below the search to narrow results by certification status, review date range, or experience status. Filters apply immediately and can be cleared with the Clear Filters button.

Reading the Results Table

Each row in the results table shows a color-coded participant name indicating their experience eligibility:

  • Green background: Participant meets the one-year experience requirement.

  • Yellow background: Participant is within one month of meeting the requirement. Consider setting to Pending with a review date.

  • Red background: Participant does not currently meet the one-year requirement. Review the prior experience section in the detail panel before denying.

Click any participant name to open the full detail panel. All columns are sortable by clicking the column header.

Processing a Certification Decision

Step 1: Open the Detail Panel

Click the participant’s name in the results table to open the full detail panel. Review all sections carefully:

  • Confirm experience status shows green (or that the calculation accounts for prior agency experience correctly)

  • Review supervisor name, agency, title, and contact information for completeness

  • Confirm a signature is present by clicking the View link in the Signature field

  • Note the program name and date — you will use this to locate the event in Novi

Step 2: Record a Preliminary Decision Status

In the Certification Decision section, you can record a preliminary status and notes while you complete verification. This is optional but useful for tracking your progress across a cohort:

  • Set Status to Pending if you are waiting on payment or exam completion

  • Add a Note explaining the current hold (e.g., “payment not yet received as of [date]”)

  • Set a Review Date for follow-up if appropriate

  • Save the decision at any point — you can update it again once all requirements are confirmed

Step 3: Verify Payment and Course Completion

Scroll to the Payment & Course Verification section within the detail panel. If Novi was already connected when the page loaded, the event search field is ready immediately — no connect step required.

Select the Event and Pull Registrations

Step Action Notes
1 Locate the event The event search field auto-populates with the program date from the submission form. A matching event is selected automatically if exactly one match is found. If not, type the date (MM/DD/YYYY), program name, or category to filter the dropdown.
2 Select the correct event Click the event name in the dropdown to select it.
3 Click Pull Registrations The tool fetches all registrant records for the selected event. A count of registrants loaded is displayed when complete.

Search for the Participant

After registrations are loaded, a Participant Name search field appears, pre-filled with the participant’s name from the submission form.

Step Action Notes
1 Confirm or edit the name The field is pre-filled with the participant’s first and last name. Edit if needed (e.g., remove a suffix, try a maiden name).
2 Click Search The tool searches both Novi registrations and TalentLMS simultaneously.
3 Review Novi payment result A payment badge appears below the search: ✓ Paid (green), ✗ Unpaid (red), or ? Unknown. If multiple Novi matches are found, click the correct registrant to confirm.
4 Review TalentLMS course completion The participant’s NCIT Basic courses load below the payment result as collapsible accordions. Each course shows completion status and percentage. Expand a course to see individual module statuses and exam scores.
5 Resolve multiple TalentLMS matches If more than one TalentLMS user matches the name, a list appears below the Novi result. Click the correct user to load their course data.

Tip: If the participant is not found in Novi registrations, they may be registered under a different name or as an attendee under another person’s registration. Try searching by last name only, or check the Novi event directly. If not found in TalentLMS, try last name only or check the User Lookup Tool.

Step 4: Issue the Certificate or Record a Denial

Once payment and course completion are confirmed, scroll down within the Payment & Course Verification section to the NCIT Course to Complete dropdown.

If Approving

Step Action Notes
1 Select the NCIT course Choose the appropriate NCIT Basic course from the dropdown.
2 Click Open in Portal TalentLMS opens in a new tab showing the course users list.
3 Complete the course Locate the participant in the list and click Complete Course next to their name. This marks the course complete and triggers the certificate of completion.
4 Return to the review tool Save your Approved decision with your name and any notes.

If Denying

Record a Denied status in the Certification Decision section with notes explaining the reason. Use the suggested message text below to notify the participant via TalentLMS or email.

Reason Suggested Message
Failed Exam Thank you for submitting your supervisor certification form for the NCIT Basic program. After reviewing your record, we are unable to process your certification at this time as our records indicate the NCIT Basic Final Exam has not yet been passed. Certification requires a score of 70% or higher. Please contact us at clearlearning@clearhq.org to discuss your options for completing or retaking the exam.
Payment Outstanding Thank you for submitting your supervisor certification form. Our records indicate an outstanding balance for your program registration. Certification cannot be processed until all fees are paid in full. Please contact us at clearlearning@clearhq.org to resolve your balance.
Insufficient Experience Thank you for submitting your supervisor certification form. After reviewing the information provided, we are unable to verify that the one-year regulatory investigations experience requirement has been met at this time. If you believe this determination is in error or if additional documentation is available, please contact us at clearlearning@clearhq.org. You may resubmit once the experience requirement has been satisfied.
Pending — Experience Nearly Met Thank you for submitting your supervisor certification form. Your record is currently under review. Based on the hire date and experience information provided, it appears the one-year regulatory experience requirement will be met in the near future. We will follow up at that time. Please contact us at clearlearning@clearhq.org with any questions.

Recording Your Decision in the Tool

Step Action Notes
1 Select a status Choose Approved, Denied, or Pending from the Status dropdown.
2 Set a review date (if applicable) For Pending decisions, a review date is recommended. The tool auto-calculates the date the participant will meet the one-year requirement. Adjust as needed.
3 Select your name Choose your name from the Reviewed By dropdown. This field is required.
4 Enter notes Add relevant context — reason for denial, payment status, exam status, or follow-up needed.
5 Click Save Decision The decision is saved immediately. The table updates to reflect the new status.

Each save adds a new entry to the Decision History log. Previous decisions are never overwritten, providing a full audit trail.

Exporting Results

After running a search, an Export to Excel button appears in the results bar. Clicking it downloads a CSV file containing all currently displayed records including certification status, review date, reviewed by, and notes. Apply any filters before exporting to get the results you need.

Troubleshooting

Issue Resolution
Submissions not loading Check your internet connection and confirm the auth token is set correctly. Try refreshing the page.
Novi Connect button stays stuck on “Connecting…” Refresh the page and try again. The Connect to Novi button is in the Search & Filter panel at the top of the page. If it continues to fail, verify your token is correct by testing it in the Exam Report Generator.
Novi events not loading after connect Confirm your token is valid. The tool loads up to 200 events — use the date or name search to filter if needed.
Participant not found in Novi registrations Try searching by last name only. The participant may be registered under a slightly different name or as an attendee under another person’s registration. Check the Novi event directly if needed.
User not found in TalentLMS Try searching by last name only. Remove suffixes (Jr., Sr., III). Use the User Lookup Tool to search TalentLMS directly.
No NCIT Basic courses showing for user The participant may not be enrolled in an NCIT Basic course. Verify enrollment in TalentLMS directly.
Save decision returns an error Confirm the SUPERVISOR_CERT_STATUS KV namespace is bound in Cloudflare. Contact Amanda Vance if the error persists.
Experience shows red but supervisor claims prior service Open the detail panel and check the Prior Regulatory Experience section. If prior experience was not entered on the form, ask the supervisor to resubmit with those dates included.
Participant shows in wrong cohort The participant may have been added to a different group in TalentLMS. Search for them by name in the User Lookup Tool.
