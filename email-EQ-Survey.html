Overview

The EQ Survey Automation Tool generates Emotional Quotient (EQ) survey result emails for individual program attendees and a cohort overview report for instructors. It pulls survey response data directly from TalentLMS, calculates scores across the four EQ domains, and produces ready-to-send HTML email files. These files are delivered through the same Power Automate process used for status report emails.

The tool is used for three programs:

  • ELPR – In-Person Program

  • ELPR – Online Program

  • So, You Think You Want to be a Board or Council Member (asynchronous)

Because the asynchronous program runs on an ongoing basis rather than in scheduled cohorts, this report should be run approximately once per month to check for new completions and send results to any learners who have recently submitted the survey.

Before You Begin

Make sure you have the following:

  • Access to the CLEAR Learning Administrative Tools Dashboard

  • Your CLEAR Learning Portal auth token (saved automatically after first use)

  • The cohort name as it appears in TalentLMS

Note: If this is your first time using the tool, you will need the auth token provided by your administrator. After the first successful connection, the token is saved in your browser automatically.

Process Guide

Part 1: Pull Survey Data

Step Action
1 From the Administrative Tools Dashboard, click the EQ Survey Automation card to open the tool.
2 If the connection status at the top does not show Connected, click Test Connection. The tool will authenticate automatically using your saved credentials.
3 In the Select Program section, click the tile for the program you are running the report for.
4 Click in the Select Group field under Cohort / Group. Type to filter the list and select the cohort you want to run the report for.
5 Click the Pull Survey Data button. The tool will fetch survey responses from TalentLMS and calculate each learner's EQ scores across the four domains.

Tip: For the So, You Think You Want to be a Board or Council Member program, there may not be a specific cohort group. Cohorts are only used for this program to identify bulk subscription purchases. In that case, leave the group field blank to pull all learners enrolled in the course who have completed the survey.

For this program, the process should be completed once a month and any new responses should be responded to.

Part 2: Review Results

Step Action
6 On the Review page, you will see the number of learners processed and the class averages for each of the four EQ domains compared to the High Functioning Threshold (HFT).
7 Below is a table showing every learner's individual scores across Self-Awareness, Empathy, Self-Motivation, and Social Skills. Scores meeting or exceeding the HFT appear in green.
8 Review the results for accuracy. When you are satisfied, click Generate Reports (top of page) or Generate All Reports (bottom of page) — both buttons do the same thing.

Part 3: Send Learner Email Reports

Each learner receives a personalized email with their individual EQ scores across all four domains, the High Functioning Threshold for reference, and a description of what each domain means.

Step Action
9 On the Generate Reports page, locate the Learner Email Reports card at the top on the left.
10 To preview an individual learner's email before downloading, click the Preview button next to their name in the table below.
11 To download a single learner's file — for example, for a late submission — click Download next to that individual's row.
12 To generate files for the entire cohort, click Download All as ZIP. This downloads a zip archive containing one HTML file per learner.
13 Navigate to your Downloads folder in File Explorer. Right-click the zip file and select Extract All. Extract the files to a location of your choice.
14 Open the extracted folder. Select all .html files.
15 In your browser, navigate to the CLEAR Staff SharePoint site. Go to: CLEAR Shared > CLEAR Learning Facilitation > Status-Report-Emails > EQ-Results.
16 Drag and drop the selected HTML files from File Explorer into the EQ-Results folder in SharePoint. Power Automate will automatically send each email from the CLEAR Learning shared mailbox.

Note: Each HTML file is named EQ_Report_[learner-email-address].html. Power Automate uses the email address in the filename to route each message to the correct recipient.

Tip: To verify that emails were sent, check the Sent folder in the CLEAR Learning shared mailbox, or navigate to the CLEAR Shared > CLEAR Learning Facilitation > Status-Report-Emails > Sent folder in SharePoint.

Part 4: Send Instructor Cohort Reports

Instructors receive a cohort-level report showing overall class averages, threshold comparisons, percentage of learners above the HFT per domain, and a full table of individual learner scores for their reference.

Step Action
17 On the Generate Reports page, locate the Instructor Cohort Report card at the top on the right.
18 Check the box next to each instructor who should receive the cohort report for this session. By default, none are pre-selected.
19 If an instructor is not in the list, enter their First Last name in the Add Instructor name field and their email address in the email field, then click + Add. They will appear at the bottom of the list, checked and ready to include.
20 To preview the instructor report before downloading, click Preview.
21 Click Download for Selected. One HTML file will be generated per selected instructor. If your browser asks permission to download multiple files, click Allow.
22 Drag and drop the downloaded HTML files directly into the CLEAR Shared > CLEAR Learning Facilitation > Status-Report-Emails > EQ-Results folder. These files do not need to be unzipped — they download individually. Power Automate will send each one from the CLEAR Learning shared mailbox.

Important: Instructor report files are named EQ_Report_[instructor-email-address].html. Make sure the email address is correct before uploading to SharePoint, especially for instructors added manually via the Add Instructor field.

Tip: The instructor report is personalized with each instructor's name in the greeting and includes the program name and cohort name in the introduction so they have full context for the results.

Quick Reference: The Four EQ Domains

Domain HFT Max Score Description
Self-Awareness 36 48 Recognizes how feelings, beliefs, and behavior affect others; accurately assesses personal strengths and limitations.
Empathy 18 24 Considers others' feelings in decision-making; understands and takes an active interest in others' concerns.
Self-Motivation 24 32 Controls disruptive impulses; maintains integrity, adaptability, and internal standards of excellence; passionate about their work.
Social Skills 18 24 Senses others' developmental needs; inspires groups; builds effective inter-personal relationships and works well with others.

Troubleshooting

Issue What to do
"Connection failed" error on load Click Test Connection. If it still fails, your auth token may have expired. Contact your administrator for a new token.
"No completed survey responses found" Confirm the correct program and cohort are selected. Verify in TalentLMS that learners have actually submitted the EQ survey, not just opened it.
Groups dropdown shows "Could not load groups" The API connection is not active. Click Test Connection and try again.
Learner is missing from the results The learner may not have completed the survey. Check their survey status in TalentLMS. You can re-run the report at any time to pick up late submissions.
Browser blocks downloading multiple files Click Allow when prompted. This is a one-time browser permission for the tool's domain.
Emails not appearing in SharePoint Sent folder Allow a few minutes for Power Automate to process. If emails have not sent after 15 minutes, check the Power Automate flow run history for errors.
