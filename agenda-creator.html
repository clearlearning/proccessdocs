Use this guide to create program agendas, instructor agendas, and Outlook calendar invites for any CLEAR Learning program using the Program Agenda Generator tool.

What this tool does

  • Create a new program agenda from scratch for any virtual or in-person CLEAR Learning program

  • Update an existing agenda by importing a previously generated PDF — useful for adding instructors or making schedule changes without starting over

  • Generate a separate Instructor Agenda PDF that lists assigned instructors per session

  • Export Outlook calendar invites (.ics) for all live sessions in one file, pre-set to start 15 minutes early

Part 1 — Creating a New Program Agenda

Step 1: Test the API Connection

When you open the tool, click the Test Connection button in the API Connection section. The status indicator will turn green when connected to TalentLMS.

Step 2: Select Your Program

Step Action
1 Under 1. Select Program, make sure the New Program tab is selected.
2

Click inside the Program Course field and type to search, or scroll the list.

Virtual programs have a light blue “Virtual” tag. In-person programs have a light green “In-Person” tag. Select the correct form of the course.
3 A confirmation message will appear below the field showing the number of sessions loaded (e.g., “✓ Loaded 13 sessions (7 Zoom, 6 self-paced)” or “✓ Loaded in-person program (3-day schedule)”).

Step 3: Complete Program Details

Step Action
1 Program Title — auto-filled from the selected course. Update only if needed.
2 Cohort / Session — enter the month and year the program starts (e.g., August 2026).
3

All Times In — select the appropriate time zone from the dropdown.

• Virtual programs: always Eastern Time (ET).

• In-person programs: use the time zone of the event location.
4 Introductory Text — auto-filled based on the selected program. Edit only if necessary. Note: this field uses HTML formatting for bold, italics, and other styling.
5

Default Session Start Time — select the start time for all live sessions in the cohort. This is typically 11:00 AM ET for virtual programs.

Once set, the schedule table will automatically populate start times for all Zoom sessions and calculate end times based on the known session duration for each session type.
6 In-person programs only — enter the Start Date (Day 1), Daily Start Time, and Location. All session times will adjust automatically.

⏱ Auto-calculated times: End times are automatically calculated from the hardcoded session duration for each session. For example, selecting 11:00 AM for Investigative Process (a 2-hour session) will set the end time to 1:00 PM. If you update a start time directly in the table, the end time will recalculate from that new start time.

Step 4: Complete the Schedule Sessions Table

Scroll down to the Schedule Sessions table. Each row represents one session. Zoom sessions require dates, times, and instructor assignments. Self-paced rows show dashes and require no input.

Step Action
1 Date column — click the date field for each Zoom session and select the session date from the calendar picker, or type it in directly.
2 Start / End times — leave as auto-populated unless a session differs from the default. Editing a start time will recalculate the end time automatically.
3 Platform — pre-set based on the program type. Only change if needed.
4 Instructor — select from the dropdown for each Zoom session. If the instructor is not yet confirmed, leave blank and return to this step later.
5 Zoom Link — paste the Zoom meeting URL for each virtual session. This field populates the Location field in the Outlook calendar invite. You may leave this blank and return to it later — Zoom links are often not available when you first create the event in Novi.

📌 Note: You will not typically have instructors or Zoom links when you first create the agenda for a Novi event. It is expected that you will return to update these fields later using the Import Existing Agenda PDF workflow (see Part 2).

Step 5: Preview and Export

Scroll down to the Preview & Export section. Use the buttons to generate the outputs you need.

Step Action
1 Preview Agenda — displays a formatted preview of the agenda in the browser. Use this to review before exporting.
2 Program Agenda PDF — exports the attendee-facing agenda. This is the PDF that is attached to the event listing in Novi.
3 Instructor Agenda PDF — exports an internal version of the agenda with instructor names listed. Marked “For Internal Use Only.” Generate this once instructors are confirmed.
4 Export Instructor Calendar Invites (.ics) — downloads a single .ics file containing one calendar event per live session. See Part 3 for how to use this file.

Part 2 — Updating an Existing Agenda (Import PDF)

Use this workflow when you need to update an agenda that was previously generated by this tool — for example, to add instructor names, update Zoom links, or change session times. You do not need to re-enter all the information manually.

Step Action
1 In Section 1 — Select Program, click the Import Existing Agenda PDF tab (next to New Program).
2 Drag and drop your existing Program Agenda PDF onto the upload area, or click the area to browse for the file.
3 The tool will read the PDF and automatically populate Program Details (title, cohort, time zone) and all session dates and times.
4 Review and update any fields in Program Details if needed (e.g., correcting a typo or changing the cohort label).
5 To change the session start time, update the Default Session Start Time picker. All session times in the table will update to reflect the new time.
6 Add or update Instructor assignments and Zoom Links in the Schedule Sessions table.
7 Export the outputs you need using the Preview & Export buttons (same as Part 1, Step 5).

⚠️ Important: Only PDFs generated by this tool can be imported. The import reads session names and dates from the PDF structure. If the PDF was created elsewhere or heavily edited outside the tool, the import may not populate correctly.


Part 3 — Exporting and Sending Instructor Calendar Invites

The Export Instructor Calendar Invites (.ics) button generates a single file containing one Outlook calendar event for every live session in the program. Each event is pre-configured with the session name, cohort, time zone, Zoom link (if entered), instructor name (if assigned), and a standard setup reminder message.

⏰ 15-Minute Early Start: Each calendar invite is set to begin 15 minutes before the agenda start time. This is the setup window for facilitators and instructors to log in, run a tech check, and resolve any issues before the session begins.

Exporting the .ics File

Step Action
1 Complete the Schedule Sessions table with session dates, times, instructor assignments, and Zoom links (if available).
2 In the Preview & Export section, click Export Instructor Calendar Invites (.ics).
3 The file will download automatically. The filename will include the cohort name (e.g., August_2026_Instructor_Invites.ics).

Importing into the CLEAR Learning Outlook Calendar

Step Action
1 Locate the downloaded .ics file and double-click it.
2 New Outlook will open to the Upload from File popup window.
3 Select the appropriate calendar from the drop-down menu (CLEAR Learning).
4 Click the Import button.

Forwarding Invites to Instructors and Facilitators

The .ics file does not automatically send invites to instructors. To get the sessions on their calendars, you can send the event invite from the CLEAR Learning calendar.

Step Action
1 Open the CLEAR Learning calendar and locate the appropriate session.
2 Click in the Required field and enter the email address for the appropriate instructor.
3 Click the Send Update button.
