Overview

The Status Report Generator pulls student progress data from the CLEAR Learning Portal (TalentLMS) and creates individual, formatted status report emails for each student in a program cohort. These emails are sent automatically through the shared CLEAR Learning mailbox using Power Automate.

Status report emails are generated at the midway point in each program and after the Program Review and Test Prep session. The midway point emails got to all attendees, the updates after the final session only go to those who have not completed the required modules.

This tool also allows you to assign the appropriate final exam to all users who have completed the required modules for their program.

This guide walks you through the full process from generating the reports to delivering them via SharePoint and Power Automate.

Before You Begin

Make sure you have the following:

  • Access to the CLEAR Learning Administrative Tools Dashboard

  • Your CLEAR Learning Portal auth token (saved automatically after first use)

  • The program name, assigned cohort, and end date for the cohort (date of the program review and test prep session)

  • Access to the CLEAR Staff SharePoint site

Note: If this is your first time using the tool, you will need the auth token provided by your administrator. After the first successful connection, the token is saved in your browser automatically.

Process Guide

Part 1: Generate the Status Reports

Step Action
1 From the Administrative Tools Dashboard, click the Status Report Generator card to open the tool.
2 Select the appropriate course from the Course list.
3 In the Group (Cohort) field, select or type the cohort name as it appears in TalentLMS.
4 In the Program End Date field, enter the date of the program review and test prep session for the cohort.
5 Review the auto-generated email text fields. These contain the standard language for status report emails.

Important: Only edit the email text for one-off situations, most likely a closed or custom program. If you do edit, make sure that anything in curly brackets ({ }) is not changed. These are placeholders and will not work if modified.

Step Action
6 Click the Pull Student Progress Data button.
7

Scroll down to review the module map. Remove the following non-required modules by unchecking them:

  • Basic US Program: Week 1 QA, Makeup Session header, and Program Review and Exam Information live session

  • Basic CAN Program: Pre-Recorded Live Sessions **Only required if you miss a live session** and Program Review & Final Exam Information - Live Session

  • Specialized Program: Recordings of Live Sessions **Only required if you miss a live session** and Live Session – Program Review & Test Prep

Note: These modules appear due to naming conventions and system limitations in TalentLMS. They are not required program elements and should not appear on student status reports.

Step Action
8

Click Generate Report & Preview. Review the cohort progress data. You can:

  • Click on an individual’s name to preview their specific email

  • Click the Email Preview button to verify email content before exporting

Part 2: Send Status Report Emails

Step Action
9 Review the rows and de-select any that you wish to exclude from the email updates

Note: When sending the midway status update, remove any rows belonging to CLEAR Staff and the CLEAR Learning account.

When sending the end of programming status update, de-select all users then review the list and re-select only those with a Progress status of In Progress.

Step Action
10 Click the Export Emails for Power Automate button. This will download a zip folder to your computer.
11 Navigate to your Downloads folder in File Explorer and locate the status report emails zip file. Right-click and select Extract All. Choose a destination and extract the files.
12 Open the extracted folder. Select all files with an .html extension.

Important: Do NOT select the file with the .json extension. Only select the HTML files.

Step Action
13 Open your browser and navigate to the CLEAR Staff SharePoint site. Go to: CLEAR Shared > CLEAR Learning Facilitation > Status Report Emails > Outbox.

Tip: Access SharePoint through your browser rather than File Explorer to ensure files upload properly.

Step Action
14 Drag and drop the selected HTML files from File Explorer into the Outbox folder in SharePoint.
15 The Power Automate process flow will automatically send each email to the address listed in the file name. Emails are sent from the CLEAR Learning shared mailbox.

Tip: To verify that emails were sent, either check the Sent folder in the CLEAR Learning mailbox or navigate to the Status Report Emails > Sent folder in SharePoint for a record of all processed files.

Part 3: Assign the Final Exam to a Cohort

Step Action
16 Complete the standard Status Report Generator process: select the course and cohort (see the Status Report Generator Process Guide, Steps 1–8).
17 Instead of exporting emails, scroll to the bottom of the page and locate the Final Exam Course field.
18 Click in the field, select all the existing text, and delete it. Type final exam to filter the options, then select the appropriate final exam course from the list.
19 Click the Assign Final Exam button. All cohort members will be added to the selected final exam course in TalentLMS.

Note: Only attendees who have reached 100% completion of the required modules will be assigned to the final exam. Do not de-select attendees who have not completed the program before assigning the test.

Repeat this process to assign the exam to attendees who finished program requirements late.

Tip: When the final exam is assigned, TalentLMS will automatically trigger an email notification to each cohort member with instructions on how to take the exam.
